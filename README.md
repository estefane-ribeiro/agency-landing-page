# 🚀 Landing Page — Agência

Landing page desenvolvida para uma agência digital, com foco em apresentar seus serviços, projetos e diferenciais de forma moderna, responsiva e profissional.

## ✨ Preview

💡 Demo: <a href"https://estefane-ribeiro.github.io/agency-landing-page/">Acesse o projeto online</a>

## 🛠️ Tecnologias

- React — construção da interface

- Tailwind CSS — estilização e responsividade

- Vite — ambiente de desenvolvimento e build

- JavaScript — lógica da aplicação

## 📋 Funcionalidades

- Design responsivo

- Seção "Sobre nós"

- Menu responsivo

- Animações e transições

## 🎨 Design

### O projeto foi desenvolvido com foco em:

- Interface moderna e minimalista

- Experiência responsiva em diferentes dispositivos

- Hierarquia visual clara

- Microinterações e animações sutis

- Consistência entre cores, tipografia e componentes

## 🚀 Como executar

### Pré-requisitos

- Node.js 18+

- npm, yarn ou pnpm

### Instalação

- Clone o repositório:
  - git clone https://github.com/seu-usuario/nome-do-projeto.git

- Entre no diretório:
  - cd nome-do-projeto

- Instale as dependências:
  - npm install

- Execute o projeto:
  - npm run dev

- A aplicação estará disponível em:
  - http://localhost:5173

## 📦 Build

- Para gerar a versão de produção:
  - npm run build

- Para visualizar o build localmente:
  - npm run preview

## 📱 Responsividade

A landing page foi desenvolvida para funcionar em diferentes tamanhos de tela:

- 📱 Mobile

- 📱 Tablet

- 💻 Desktop

- 🖥️ Telas maiores
